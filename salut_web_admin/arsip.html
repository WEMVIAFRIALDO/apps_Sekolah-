Upload dan kelola dokumen kelulusan alumni (REQ-NF-01: Private JWT)

Keamanan Dokumen (REQ-NF-01)
Semua dokumen tersimpan di private storage. Akses hanya bisa dilakukan melalui endpoint API dengan autentikasi Bearer Token JWT yang valid.
Struktur Storage Hierarkis
Sesuai SRS REQ-NF-02: angkatan_{year}/nisn_{nisn}/{doc_type}.pdf
📁 storage/app/
  └── 📁 angkatan_2024/
     └── 📁 nisn_0067890123/
         ├── 📄 ijazah.pdf ✅
         ├── 📄 skhun.pdf ✅
         └── 📄 skl.pdf ✅
📋 Panduan Upload
  1. Klik tombol "Upload Dokumen" di kanan atas
  2. Masukkan User ID alumni yang bisa dilihat di halaman Siswa & Alumni
  3. Pilih jenis dokumen (Ijazah / SKHUN / SKL / Rapor)
  4. Upload file PDF (maks. 20MB)
  5. Alumni akan bisa download via aplikasi Android dengan JWT
