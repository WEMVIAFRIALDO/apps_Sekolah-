LAPORAN 3
PENGEMBANGAN BACKEND API DAN KONFIGURASI BASIS DATA

1. Konfigurasi Lingkungan Backend (Laravel)

Pada tahap ini, dilakukan persiapan lingkungan backend menggunakan framework Laravel versi 12. Konfigurasi awal difokuskan pada pengaturan variabel lingkungan di dalam file .env, khususnya untuk menghubungkan aplikasi Laravel dengan database relasional (MySQL) dan secret key HMAC-SHA256 untuk JWT Auth.

2. Pembuatan Struktur Database (Migration dan Model)

Setelah koneksi berhasil, dirancang struktur database multi-role (Admin, Guru, Siswa Aktif, Alumni) menggunakan Migration Laravel agar skema database terstruktur, aman, dan mudah di-reproduksi.

3. Pembuatan Endpoint API dan Implementasi Autentikasi JWT

Sistem SALUT menggunakan arsitektur Client-Server dengan 23 endpoint RESTful. Rute login publik disediakan pada POST /api/login, sedangkan rute modul lainnya diproteksi ketat menggunakan middleware jwt.auth.

4. Pengujian API (API Testing)

Pengujian dilakukan menggunakan perangkat lunak API Client. Server sukses merespons status 200 OK serta mengembalikan payload token akses JWT beserta objek data profil pengguna.

5. Penyimpanan Repositori Backend ke GitHub

Seluruh source code backend disimpan ke version control system GitHub pada repositori WEMVIAFRIALDO/apps_Sekolah-.

LAPORAN 4
PENGEMBANGAN ANTARMUKA MOBILE (FLUTTER) DAN INTEGRASI API

1. Pembuatan Antarmuka Pengguna (UI) Utama

Pada tahap ini, pengembangan beralih ke mobile menggunakan framework Flutter. Dibuat halaman login_page.dart yang responsif dengan form validasi nomor induk dan kata sandi.

2. Integrasi HTTP Request dan Pengelolaan Token JWT

Aplikasi Flutter dikonfigurasi menggunakan pustaka HTTP client Dio dengan arsitektur Interceptor pada ApiService untuk otomatisasi penyisipan Bearer Token pada setiap request keluar.

3. Simulasi dan Pengujian Antarmuka pada Perangkat Mobile

Aplikasi dijalankan langsung pada gawai cerdas (smartphone) untuk menguji alur autentikasi dan rendering antarmuka pengguna.

LAPORAN 5
PENGEMBANGAN FITUR LANJUTAN EKOSISTEM KEJURUAN SMK (PORTOFOLIO SKPI & ARSIP DOKUMEN DIGITAL)

1. Perancangan Skema Database Portofolio Keahlian (SKPI)

Dibuat tabel skill_competencies untuk mendokumentasikan capaian unit keahlian siswa SMK, nilai asesmen, tingkat kemahiran (Dasar, Terampil, Mahir), dan nama guru penguji LSP terlisensi BNSP.

2. Implementasi Controller API Portofolio Keahlian

Dibangun SkillController.php dengan endpoint GET /api/skills/my yang menyajikan daftar capaian portofolio kejuruan siswa yang terautentikasi.

3. Pengembangan Halaman Portofolio Keahlian Mobile (skills_page.dart)

Pada aplikasi Flutter, dibangun antarmuka skills_page.dart yang menyajikan kartu-kartu sertifikasi kompetensi keahlian siswa secara interaktif.

LAPORAN 6
INTEGRASI PUSH NOTIFICATION, OTOMASI TRANSISI KELULUSAN, DAN PENGUJIAN MENYELURUH

1. Integrasi Push Notification Firebase Cloud Messaging (FCM)

Dipasang fcm_service.dart untuk menangani penerimaan notifikasi siaran pengumuman kelulusan dan kuesioner tracer study secara langsung pada smartphone pengguna.

TEMPAT SCREENSHOT ASLI DARI HP

Ambil tangkapan layar langsung dari HP saat banner Push Notification kelulusan muncul di layar atas

2. Otomasi Transisi Status Siswa ke Alumni (Scheduled Cron Job)

Dibangun command artisan salut:promote-alumni yang dijadwalkan otomatis setiap hari jam 00:00 untuk mengubah role siswa yang telah lulus menjadi alumni tanpa intervensi manual admin.

3. Peningkatan Keamanan Pengguna: Modul Ubah Kata Sandi Mobile

Disediakan modul change_password_page.dart untuk validasi dan pembaruan kata sandi pengguna secara terenkripsi bcrypt.

4. Implementasi Kuesioner Tracer Study Alumni

Kuesioner tracer study mencatat riwayat penyerapan kerja alumni (Bekerja, Kuliah, Wirausaha) beserta data nama perusahaan, prodi kampus, dan rentang penghasilan.

TEMPAT SCREENSHOT ASLI DARI HP
Tampilan Kuesioner Tracer Study

5. Analitik Ekosistem Kejuruan SMK pada Web Admin

Web Admin panel menampilkan visualisasi data analitik penyerapan lulusan (65% bekerja di industri DUDI, 25% kuliah, 10% wirausaha/lainnya) serta top mitra institusi penyerap alumni.

6. Rilis Final dan Tagging Repositori GitHub

Setelah seluruh fitur diuji secara end-to-end dengan hasil 0 error, proyek dirilis secara resmi dengan tag v1.0.0-smk-release di GitHub.
